# SportsFoundry SDKs

Official first-party SportsFoundry client libraries generated from the canonical public SportsFoundry API contract.

Initial packages:
- TypeScript / JavaScript: `@sportsfoundryapp/sdk`
- Python: `sportsfoundry`
- Java: `app.sportsfoundry:sportsfoundry-java`
- .NET: `SportsFoundry`

Canonical public contract: `https://sportsfoundry.app/openapi/public-v1.json`
